# Changelog

## 1.1.0

- Quests keep the currencies they reward, and `TylesserData.QuestsRequiring(itemID)` lists the quests that ask for an item, with those rewards (used by Tylesser - Commerce Authority for crate Favor).
- Files from game clients in other languages add only what has no language (places, levels, loot, prices); their names and texts are left out, so the data stays in one language.

## 1.0.0

- First release: the API (see the README) and the first data shared with Tylesser - Collector.
